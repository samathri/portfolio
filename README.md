# Creative Bot Portfolio

Interactive React portfolio for an AI Prompt Engineer.

## Install

```cmd
cd C:\xampp\htdocs\portfolio
npm install
npm run dev
```

Open the URL shown by Vite, usually:

```text
http://127.0.0.1:5173
```

## Build

```cmd
npm run build
```

## Customize

Edit `src/main.jsx` and update the `profile` object at the top.
